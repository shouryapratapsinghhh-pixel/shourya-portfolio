P.03

TraceLens

Sep 2026

Target-centric CCTV video summarization

Caught a flawed evaluation metric that hid 3.6 wrong identity merges per target. Redesigned it at the identity level, tuned on 2 sequences, reported only on 5 held-out ones.

Multi-object tracker built from scratch (Kalman filter, Hungarian matching, camera-motion compensation via optical flow + RANSAC), scored under the official MOT17 protocol and verified identical to TrackEval. Gains were confined to moving-camera sequences: MOT17-10 IDF1 rose 0.39 → 0.54.

Event detection for loitering, running, restricted-zone entry and abandoned objects, robust up to 10% detector misses with 0 false alarms on non-target pedestrians. Incident narration by Qwen2.5-1.5B, grounded in the event log and checked by a deterministic hallucination checker: 100% of real LLM output verified.

Python / PyTorch / OpenCV / SciPy / Transformers / Streamlit
